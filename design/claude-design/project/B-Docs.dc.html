1. Откуда берутся данные

Boris работает сразу после установки. Он читает файлы, которые Claude и так пишет на диск, и ничего в них не меняет. Аккаунт не нужен, интернет нужен только для Telegram, обновления приложения и обновления лимитов.

Что видно без хуков

Всё: сессии, агенты, текущий шаг, токены, сбои и лимиты. Обновления приходят с небольшой задержкой, а ответить на запрос Claude можно только в самом Claude.

Что дают хуки

События приходят мгновенно, и на запросы можно отвечать прямо из Boris. Перед подключением Boris показывает точные изменения настроек Claude, отключить их можно в «Подключениях». Если хуки сломались, данные продолжают обновляться, а Boris предлагает их починить.

Чат и Cowork

Для чата известно только, что ответ готов, и для этого нужно разрешение Accessibility. Для Cowork данных намного больше, но на его запросы отвечают в Claude Desktop.

4. Агенты, статусы и сбои

Сессия держит главного агента, он может звать субагентов, а workflow запускает целую группу агентов по фазам. Фазы берутся из журнала (started.phase) и из meta.phases скрипта. Число агентов заранее неизвестно и растёт по ходу, поэтому шкала прогресса может откатиться назад.

Причины сбоев

Boris называет причину своими словами, а сырой текст ошибки показывает только в деталях. Он берётся из последней записи транскрипта агента, а если её нет, из поля reason в журнале.
