# Макет Boris из Claude Design

Снимок холста [«Борис 1.0»](https://claude.ai/artifact/TDZ3z8FhUUVZL1rNCJst28), страница «Boris · бриф 5 ноября». Источник правды по внешнему виду остаётся на холсте, здесь его копия для работы.

- **Версия холста:** `1793882706-e89a`
- **Снято:** 2026-11-05
- **Состав:** 29 экранов `B-*`, используемые ими компоненты `Owl`, `Ribbon`, `StatusIcon` и индекс `canvas.json`. Архивная страница не сохранялась, хотя упоминается в индексе.

## Что уточняется при сборке

- На странице «Морж» имена нарядов и реакций это примеры. Настоящие берутся из кода моржа: наряды Новый год, Хэллоуин, праздник, 1 сентября, ночь, 8 марта, 14 февраля и другие; реакции зевок, тык, раздражён, спиной, подмигнул, оборот, голова кружится.
- Порог молчания в настройках показан как 10 минут, а по умолчанию он 12 минут.
- «Не давать Mac уснуть» показано включённым, а по умолчанию выключено.
- В «Подключениях» нет состояния «хуки не подключены» с кнопкой «Подключить ответы». Оно строится по образцу других состояний.
- Окно `B-Docs` пока не переносится: лёгкую документацию напишем отдельно.

## Как с этим работать

Это HTML-макет, а приложение пишется на SwiftUI. В приложение он не встраивается: из него берутся токены, тексты, размеры и состояния. Подробности в решении 27 в [design.md](../../openspec/changes/boris-product-vision/design.md).

- Морж в макете это заглушка (`Owl`). Настоящий морж вставляется при сборке из готового кода.
- Цвета бренда в `B-Kit` временные. При сборке они заменяются цветами моржа из кода.
- Экраны здесь фиксированного размера, поэтому адаптивность и стабильность проверяются снимками самого приложения, а не на макете.

После правок на холсте снимок надо обновить и записать здесь новую версию.
