# Spec Delta

## Purpose

Даёт пользователю решать, за какими продуктами и средами следит Boris и что можно делать с их данными: считывать, уведомлять, отвечать на запросы и снимать на экран.

## ADDED Requirements

### Requirement: Настройка источников
Boris SHALL иметь в настройках раздел «Источники» со списком: Claude Code в терминале, VS Code, Cursor, на вкладке Code и на удалённых машинах, программы на Agent SDK, а также Cowork и чат Claude. Для каждого источника MUST быть свои переключатели.

#### Scenario: Открытие раздела
- **WHEN** пользователь открывает раздел «Источники»
- **THEN** он видит все источники с переключателями «Считывать», «Уведомлять», «Отвечать на запросы» и «Снимки экрана»

#### Scenario: Функция недоступна для источника
- **WHEN** источник не поддерживает ответы на запросы, например чат Claude
- **THEN** этот переключатель неактивен с пояснением причины

### Requirement: Считывание по источникам
Boris SHALL позволять включать и выключать считывание для каждого источника и сразу для всего продукта. Для выключенного источника Boris MUST NOT читать его файлы и показывать его данные.

#### Scenario: Выключен один источник
- **WHEN** пользователь выключает считывание для Cursor
- **THEN** сессии Cursor исчезают из Boris, а его файлы и события больше не обрабатываются

#### Scenario: Выключен весь продукт
- **WHEN** пользователь выключает Claude Code целиком
- **THEN** считывание выключено для всех его сред, а Cowork и чат работают по своим настройкам

#### Scenario: Источник включён снова
- **WHEN** пользователь снова включает считывание
- **THEN** Boris восстанавливает данные из логов, которые хранит Claude, и показывает их

### Requirement: Значения по умолчанию
По умолчанию считывание SHALL быть включено для всех источников, кроме чата Claude, которому нужно согласие на разрешение Accessibility. Снимки экрана по умолчанию SHALL быть разрешены. Настройки MUST сохраняться между запусками.

#### Scenario: Первый запуск
- **WHEN** пользователь запускает Boris впервые
- **THEN** включены все источники, кроме чата Claude

### Requirement: Итоги при выключенных источниках
Если часть источников выключена, расход и другие итоги SHALL считаться без них, и Boris MUST показывать, что учтены не все источники.

#### Scenario: Страница «Расход»
- **WHEN** считывание Cowork выключено и пользователь открывает «Расход»
- **THEN** итог не включает Cowork, а рядом указано, что учтены не все источники

### Requirement: Уведомления по источникам
Boris SHALL позволять отключать уведомления отдельно для каждого источника, не выключая его считывание.

#### Scenario: Уведомления выключены
- **WHEN** для терминала выключены уведомления и там упал агент
- **THEN** сбой виден в Boris, но уведомления и звука нет

### Requirement: Ответы на запросы по источникам
Boris SHALL позволять отключать ответы на запросы отдельно для каждого источника. Для такого источника запрос MUST сразу оставаться в обычном интерфейсе Claude, без ожидания Boris.

#### Scenario: Ответы выключены
- **WHEN** для VS Code выключены ответы и Claude там просит разрешение
- **THEN** запрос без задержки обрабатывается в VS Code, а Boris показывает только, что сессия ждёт ответа

### Requirement: Снимки экрана по источникам
Boris SHALL позволять запретить снимки экрана отдельно для каждого источника. Окно с данными такого источника MUST скрываться от снимков, записи и показа экрана, насколько это позволяет система.

#### Scenario: Снимки запрещены
- **WHEN** для Cowork запрещены снимки и открыта его сессия
- **THEN** окно Boris не попадает в снимок экрана и показ экрана

#### Scenario: В окне данные разных источников
- **WHEN** окно показывает данные и разрешённых, и запрещённых источников
- **THEN** всё окно скрывается от снимков

#### Scenario: Система не гарантирует защиту
- **WHEN** пользователь запрещает снимки
- **THEN** настройки поясняют, что некоторые способы захвата экрана могут обойти запрет

### Requirement: Настройки не влияют на Claude
Выключение источника MUST NOT менять работу Claude и его файлы.

#### Scenario: Выключено всё
- **WHEN** пользователь выключает считывание всех источников
- **THEN** Claude работает как обычно, а Boris показывает, что источники выключены
