- Boris starts again after you replace a copy built from source with a release. macOS refused to start the login copy, which still carried the old signature, so Boris did not run at all. Now the login item is registered again for the new copy.
- A copy you open by hand hands over to the login copy only once that one is really running. If it cannot start, Boris simply keeps running.
- `scripts/install.sh` no longer leaves a half-replaced app when the installed copy is a notarized release.
