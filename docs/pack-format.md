# Формат набора Boris

Набор заменяет моржа файлами: картинки по состояниям, значок для трея, реплики на разных языках и звуки. Встроенный морж остаётся нарисованным в коде и никуда не девается: к нему всегда можно вернуться на странице «Морж».

В наборе нет кода и скриптов, только картинки и текст. Boris копирует к себе только файлы, перечисленные здесь, всё остальное в папке он не трогает и не читает.

## Как устроена папка

Набор это обычная папка. Её выбирают кнопкой «Импортировать набор…» на странице «Морж».

```
Борис в отпуске/
  pack.json             описание, обязательно
  poses/
    base/               базовая поза, обязательно
      1.png
    working/            анимация состояния, необязательно
      1.png
      2.png
      3.png
    alarm/
      1.png
  icon/
    base.png            одноцветный значок для трея, обязательно
    alarm.png           значок для состояния, необязательно
  lines/
    en.json             реплики на базовом языке, обязательно
    ru.json             перевод, необязательно
  sounds/               звуки, необязательно
```

## Описание: pack.json

```json
{
  "name": "Борис в отпуске",
  "author": "Ваше имя",
  "baseLanguage": "en",
  "framesPerSecond": 8
}
```

| Поле | Обязательно | Что значит |
|---|---|---|
| `name` | да | Название на странице «Морж», первые 80 символов. Набор с тем же названием при импорте заменяется: так приходит новая версия. Если старая версия была выбрана, выбранной остаётся новая. |
| `baseLanguage` | да | Код языка, на котором реплики есть полностью: `en`, `ru`. |
| `author` | нет | Показывается рядом с названием, первые 80 символов. |
| `framesPerSecond` | нет | Скорость анимации, от 1 до 24. По умолчанию 8. |

## Состояния: poses/

В папке состояния лежат кадры в формате PNG с прозрачным фоном. Они идут по порядку номеров: `2.png` раньше `10.png`. Один кадр это неподвижная картинка.

| Папка | Когда показывается |
|---|---|
| `base` | Обязательная основа. Витрина, «О Boris» и замена всего, чего нет в наборе. |
| `working` | Идёт работа |
| `waiting` | Нужен ответ |
| `happy` | Готово |
| `hmm` | Готово с ошибками или остановлено |
| `alert` | Давно без новостей |
| `tired` | Лимит близко или кончился |
| `alarm` | Упало или оборвалось |
| `broken` | Boris не читает данные |
| `sleeping` | Ничего не идёт |

Любого состояния, кроме `base`, может не быть: вместо него покажется базовая поза.

Кадр показывается на разных поверхностях размером от 28 до 190 точек, поэтому рисовать лучше квадрат 512 на 512 или больше. Картинка уменьшается с сохранением пропорций.

Как и у встроенного моржа, долгие состояния (`waiting`, `tired`, `broken`, `sleeping` и `base`) в обычной работе стоят на первом кадре: то, что может длиться часами, не должно тратить процессор. Все кадры видны в предпросмотре на странице «Морж». Анимация не идёт, если морж не виден или включено уменьшение движения. В памяти держится до 48 кадров, поэтому более длинная анимация стоит дороже: её кадры читаются с диска снова.

## Значок для трея: icon/

`icon/base.png` обязателен, значки по состояниям (те же имена, что у папок в `poses`) нет. Значок одноцветный: важна только прозрачность, цвет задаёт система под тему строки меню. Размер 42 на 36 пикселей. Значок всегда неподвижный.

## Реплики: lines/

Один файл на язык, имя файла это код языка:

```json
{
  "poke": ["Я в отпуске."],
  "request": ["Вас ждут.", "В {project} ждут вашего слова."],
  "finish": ["Готово."],
  "failure": ["Что-то упало.", "В {project} что-то упало."],
  "limit": ["Лимит на пределе."]
}
```

| Ключ | Когда звучит |
|---|---|
| `poke` | По нажатию на моржа |
| `request` | Claude ждёт ответа |
| `finish` | Работа закончена |
| `failure` | Работа упала или прервалась |
| `limit` | Лимит близко или кончился |

- В файле базового языка должны быть все пять ключей, и у каждого хотя бы одна реплика без `{project}`: не у всех событий есть проект.
- `{project}` заменяется названием проекта. Реплики показываются как есть, форматов кроме этого нет.
- Реплика длиной не больше 240 символов.
- Если для языка интерфейса нет файла или в нём нет ключа, морж говорит на базовом языке.

## Звуки: sounds/

Файлы `aiff`, `wav`, `m4a`, `mp3` или `caf` принимаются и копируются вместе с набором, но пока не воспроизводятся: голос моржа появится позже, и тогда здесь будут описаны имена файлов.

## Что проверяется при импорте

Набор либо импортируется целиком, либо не импортируется совсем. Boris показывает весь список того, что нужно исправить, а не первую ошибку. Набор не применяется, если:

- нет `pack.json`, или он не читается, или в нём нет `name` или `baseLanguage`;
- в `poses/base` нет ни одной картинки;
- нет `icon/base.png`;
- нет файла реплик на базовом языке, в нём нет какого-то ключа или все реплики ключа с `{project}`;
- реплика длиннее 240 символов;
- файл не читается как PNG, больше 8 МБ или больше 2048 точек по стороне;
- в одной папке больше 240 кадров, или весь набор больше 256 МБ;
- вместо файла или папки лежит символическая ссылка.

Файлы других типов и лишние папки просто не копируются.

## Где наборы лежат

Импортированный набор копируется в `~/Library/Application Support/Boris/Packs/`, поэтому исходную папку можно удалить. Если файлы набора потом пропали или испортились, вместо них покажется встроенный морж.

## Чем набор отличается от встроенного моржа

Наряды и реакции на мышь есть только у встроенного: наряды умножили бы число кадров на все позы. По нажатию морж из набора говорит реплику, но кадры не меняются. Набор работает на всех поверхностях: в трее, чёлке, мини-окне и главном окне.
